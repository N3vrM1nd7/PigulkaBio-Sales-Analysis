## Project Notes

1. About the dataset: This is a synthetic dataset based on real-world data. All values, names, and IDs have been pseudonymized, anonymized, and modified to ensure confidentiality. Every step taken to modify the data was discussed with and approved by the data owner. None of the findings relate to any actual company. The dataset has been approved for publication in the form provided at the following link: https://github.com/N3vrM1nd7/PigulkaBio-Sales-Analysis/blob/main/data/dataset_github.xlsx.
   
2.	Data analysis and AI usage: The analytical phase - including data exploration, the creation of pivot and standard tables, visualization, and the development of formulas - was carried out independently in Excel. AI models (Claude and ChatGPT) were used to verify calculations, refine specific parts of the text, and assist with the visual presentation on GitHub (e.g., formatting text into tables, adjusting the size and placement of charts, and designing KPI cards). The research questions, calculations, and conclusions are my own.
   
3.	Presentation: The project found at https://github.com/CamilingJS/TechSphere_Ecommerce/blob/main/README.md served as a reference. I drew inspiration from the presentation style and visual layout of the TechSphere project.

4.	Company name and logo: The logo used in this project was generated by AI, and the company name is entirely fictional. Any resemblance to an actual company is purely coincidental.
